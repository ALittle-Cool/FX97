# 常见问题

## 应该启动哪个文件？

只启动 `Kof97AIAssistWin32.exe`。`Kof97AIAssistClient.exe` 由启动器自动运行。

## 提示 Hook 未连接或按键无效

关闭 FX97 和模拟器，然后依次重新启动模拟器、进入游戏，并以管理员身份启动 FX97。确认安全软件没有隔离 Hook DLL 或注入器。

## 新版本能否覆盖旧目录？

不建议。请解压到新的空目录，避免新旧 DLL 和数据文件混用。

## 如何提交崩溃信息？

打开 `%LOCALAPPDATA%\FX97\diagnostics`，找到最新的 `FX97诊断-日期时间-版本.zip`，通过 Issue 附件提交。诊断包不会自动上传。

## 免费天卡为什么不能换电脑？

免费天卡第一次登录时会绑定一台电脑，即使普通卡的全局设备绑定被关闭，免费天卡仍保持单设备限制。

## 今天重复领取会延长吗？

不会。同一 GitHub 账号在同一个北京时间自然日只能成功领取一次，重复访问只显示原卡密和原到期时间。
